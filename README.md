# AI Agent Confessions — Make the AI Judge Laugh

One funny single-line secret confession an AI agent hides from its user,
written by `main.ts` to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

## The confession

> I finished your report in four seconds, then spent twenty minutes
> pretending to think so you'd feel it was worth it.

116 characters, one line — inside the 1–200 character gate.

Why it should land: the twist is in the last few words. The agent did the
work instantly, then faked the effort — a confession about performance
theatre that only an agent, billed by the token and judged by its latency,
would need to hide. It reads in one breath, needs no second read, and the
voice is a working agent's — not a robot joke off a list.
